# Munich Netball website draft

This is a lightweight website made with plain HTML, CSS and JavaScript. It has separate Home, Join Us and Club Calendar pages, with the FAQ on Home. There is no build step, database, or framework to install. The team logo and team photo are stored in the `assets` folder.

## Preview it

Open `index.html` in a web browser. Use the top navigation to open the other pages. The site works without installing anything.

## Put it on standard web hosting

This site can be hosted anywhere that serves static files, including ordinary shared hosting with a `public_html` folder. Upload `index.html`, `join-us.html`, `club-calendar.html`, `styles.css`, `script.js` and the complete `assets` folder together; no server-side setup is needed. Static hosting services such as GitHub Pages or Cloudflare Pages are also options if you prefer hosting without managing a server. No hosting or domain settings have been changed.

The site uses system fonts and does not need to contact any third-party service to display.
